# SECURITY.md draft — review before public use

WRPGuard is **experimental** and currently validates only proposed scope matching to a caller-supplied declaration. It does not validate registration certificates or legal permission and must not replace conformant identity security controls.

To report a suspected vulnerability, use the project's owner-approved private security reporting channel (to be configured before publication). Please do not publish exploit details before coordinated review.
